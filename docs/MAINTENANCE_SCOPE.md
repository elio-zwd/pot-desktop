# Pot 社区维护版维护范围

## 1. 项目定位

Pot 社区维护版是基于 Pot 3.0.7、继续遵循 GPL-3.0 的非官方社区维护分支。它不代表官方 Pot，也不是 Manggo 的组成部分或官方继任项目。

维护仓库：`https://github.com/elio-zwd/pot-desktop`

稳定主线：`custom/main`

初期正式支持平台：Windows x64。

## 2. 第一优先级

以下问题优先进入评估和修复：

1. 插件平台、插件安装、插件执行与兼容性；
2. Windows x64 的启动、快捷键、剪贴板、窗口和稳定运行；
3. 凭据泄露、明文传输、任意代码执行、用户数据破坏等安全问题；
4. 构建链、测试门禁和后续发布链；
5. 主要 AI 或翻译接口因上游 API 变化而完全失效；
6. 已稳定合入的设置 Schema V2、结果 Schema V2 和旧版插件兼容回归。

## 3. 第二优先级

在有可复现证据、修改范围可控且有人能够验证时，维护版会尽力处理：

- macOS、Linux 的关键问题；
- 常用内置服务的明确故障；
- 性能、可访问性和开发体验改进；
- 风险较低、与维护版目标用户直接相关的上游修复。

这些项目属于“尽力兼容”，不等同于正式发布支持。

## 4. 默认不承担

维护版默认不承诺：

- 接管全部上游 Issue 或历史遗留问题；
- 维护所有低使用率服务；
- 与 Manggo 进行完整产品线竞争；
- 在首阶段迁移 Tauri 2；
- 整体升级 React、NextUI、Rust/Tauri 或依赖栈；
- 大规模重做全局 UI；
- 为未经复现、缺少日志或无法说明影响的问题安排开发；
- 为非官方构建提供固定响应时限或商业 SLA。

## 5. 正式支持与尽力兼容

### 正式支持

“正式支持”表示维护者会把该平台纳入发布前门禁，并在已知限制内提供可复现的构建、测试和问题处理流程。首阶段仅承诺 Windows x64。

### 尽力兼容

“尽力兼容”表示代码可能继续适用于其他平台，但没有固定发布矩阵、签名产物和完整回归承诺。macOS 与 Linux 当前属于此范围。

## 6. 问题接受依据

问题通常在满足以下条件时进入处理：

- 能说明版本、平台、复现步骤、预期结果和实际结果；
- 能提供脱敏日志、最小配置或测试样例；
- 与维护范围和目标用户相关；
- 不要求提交真实 API Key、签名材料或用户隐私数据；
- 修改规模、风险和长期维护成本可接受；
- 不需要在同一 PR 混入无关依赖升级或大规模重构。

## 7. 问题拒绝或暂缓依据

以下情况可被拒绝、关闭或标记为暂缓：

- 无法复现且长期缺少必要信息；
- 仅影响未正式支持平台，且没有验证资源；
- 与本维护版目标无关或维护成本明显过高；
- 要求使用上游签名、官方更新通道或真实用户凭据；
- 需要整体迁移技术栈、重做全局 UI 或同时修改多个无关模块；
- 已有更安全、范围更小的替代方案；
- 应由上游、插件作者或第三方服务处理。

## 8. 反馈边界

本维护版的问题应提交到 `elio-zwd/pot-desktop`。请勿以本维护版问题向官方 Pot、原作者或 Manggo 要求支持。
